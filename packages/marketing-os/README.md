# Aksh Health Marketing OS

Public marketing website for Aksh Health — the AI Healthcare Operating System.

## Tech stack

- Next.js 14 App Router
- TypeScript (strict)
- Tailwind CSS + shadcn/ui
- Inter (Google Fonts)

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3010

## Build

```bash
npm run build
npm start
```

## Routes

| Route | Description |
|-------|-------------|
| `/` | Homepage |
| `/platform` | Platform architecture |
| `/for-clinicians` | GP + nurse conversion |
| `/for-hospitals` | Hospital Command Centre |
| `/for-patients` | Patient Health Companion |
| `/for-administrators` | Practice + ICS admin |
| `/pilot` | NHS pilot programme |
| `/pilot/apply` | Pilot application form |
| `/docs` | Documentation portal |
| `/signup` | Role-aware sign up |
| `/use-cases/*` | Case study stubs |
