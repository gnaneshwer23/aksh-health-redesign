# UK V1 MVP Screens

## 1. Dashboard
Purpose: orient the reviewer and show system status.

Show:
- number of pending cases
- number of flagged cases
- recent accepted cases
- workflow summary cards

## 2. Review Queue
Purpose: let the clinician choose the next case.

Show:
- patient alias or synthetic case id
- source type
- safety severity
- status
- last updated time

## 3. Case Review
Purpose: review and finalize one generated draft.

Show:
- encounter summary
- conditions
- medications
- observations
- safety flags
- reviewer notes
- accept, reject, defer actions

## 4. Audit Summary
Purpose: show proof of traceability.

Show:
- input received
- draft generated
- safety checks completed
- edits made
- final decision
- timestamps and actor
